## 平台对比

### 推荐理由

1. **多抓鱼**：最推荐的二手书平台，书籍品相有保障，价格合理，操作便捷
2. **孔夫子旧书网**：书源最丰富，适合查找稀缺书籍
3. **小谷吖**：小程序体验好，适合快速交易
4. **漫游鲸**：多渠道支持，选择灵活

### 购买建议

- 普通畅销书：优先选择 **多抓鱼**
- 古籍珍本：优先选择 **孔夫子旧书网**
- 快速交易：优先选择 **小谷吖**
